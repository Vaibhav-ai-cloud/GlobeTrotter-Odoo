# 🌍 GlobeTrotter-Odoo

> **AI-powered personalized travel planning built on Odoo 19 Community.**

GlobeTrotter turns complex travel planning into one connected experience — from **discovering destinations to building itineraries, managing budgets, and sharing trips**.

## ✨ Core Features

* 🧳 Multi-city trip planning
* 📍 City & activity discovery
* 🗓️ Day-wise itinerary builder
* 💰 Budget & cost tracking
* 🤖 Personalized recommendations
* 📅 Calendar / timeline planning
* 🔗 Shareable itineraries

## 🏗️ Technology

**Odoo 19 Community · Python · PostgreSQL · XML · OWL · Docker · GitHub**
